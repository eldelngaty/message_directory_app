## Student Information

## Description
This application is a simple Message Directory built using React Native and Expo Router.

The app contains multiple directories:
- Family
- Friends
- Work
- University
- Travel

When the user selects a directory, the application displays the messages associated with that directory.

## Features
- Home screen with directory list
- Navigation between screens
- Different messages for each directory
- Simple and clean user interface
